# Doce Pedido

Aplicação web acadêmica desenvolvida para o Projeto Integrador Transdisciplinar em Engenharia de Software II. A solução representa uma confeitaria de cupcakes com catálogo, conta do cliente, carrinho, pedidos e recursos complementares de segurança, privacidade, responsividade e PWA.

- **Aplicação publicada:** https://docepedido.pythonanywhere.com/
- **Repositório:** https://github.com/braianperuzzo/DocePedido
- **Back-end:** Python com Flask
- **Front-end:** Jinja, HTML, CSS, JavaScript e Bootstrap
- **Persistência:** SQLite com SQLAlchemy
- **Hospedagem:** PythonAnywhere
- **Plataforma:** Aplicação Web responsiva com PWA

## Funcionalidades

- Home, catálogo, busca, filtros e detalhes de produtos;
- cadastro com CPF e confirmação por e-mail;
- autenticação, recuperação de senha e validação de dispositivo;
- Minha Conta, edição de dados, endereços, favoritos e exclusão da conta;
- carrinho, estoque e cupom `BEMVINDO` para primeira compra;
- revisão do pedido com entrega ou retirada;
- Pagamento Presencial como forma ativa;
- confirmação de pedido, e-mail transacional e histórico em Meus Pedidos;
- tema claro e escuro, interface responsiva, PWA e modo offline;
- cookies, privacidade, segurança e recursos de SEO.

## Situação Final

A aplicação está publicada e os fluxos principais foram validados. A documentação registra modelagem, implementação, testes técnicos, avaliações externas, correções, reteste e evidências da versão final. Os artefatos específicos de PIT I e PIT II permanecem separados das seções técnicas para facilitar a avaliação acadêmica.

A pasta [`documentacao/06-PIT-2/`](documentacao/06-PIT-2/) reúne o documento oficial em DOCX, Markdown e PDF, os dois vídeos exigidos para a entrega e o material da disciplina.
