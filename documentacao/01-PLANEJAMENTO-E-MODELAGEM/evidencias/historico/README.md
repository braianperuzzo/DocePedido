# Evidências Anteriores

As imagens desta pasta preservam estados anteriores reais da interface ou recortes/extratos de evidências históricas já presentes no documento oficial da PIT II. São utilizadas exclusivamente para rastreabilidade das correções.

| Arquivo | Comparação |
| --- | --- |
| `01-offline-antes.png` | tela offline antes da simplificação |
| `02-catalogo-antes.png` | catálogo antes da compactação e dos filtros |
| `03-produto-antes.png` | detalhe do produto antes da reorganização |
| `04-faq-antes.png` | FAQ antes da revisão de layout, contraste e padronização textual |
| `05-home-mobile-antes.png` | Home mobile antes da reorganização responsiva |
| `06-rodape-antes.png` | estado anterior do rodapé/conteúdo institucional, extraído de evidência real do documento oficial |
| `07-finalizacao-direta-antes.jpeg` | fluxo anterior chegando diretamente à finalização, extraído de evidência real do documento oficial |
| `08-padronizacao-textual-antes.png` | recorte real da FAQ antes da padronização de capitalização e terminologia |

## Integridade

Nenhuma imagem desta pasta foi criada para simular um erro inexistente. Os arquivos `06`, `07` e `08` apenas recortam ou extraem conteúdo de evidências reais já preservadas no documento oficial, sem alterar o conteúdo visual da tela.

A matriz completa está em [`../../../03-TESTES-E-QUALIDADE/EVIDENCIAS_ANTES_DEPOIS.md`](../../../03-TESTES-E-QUALIDADE/EVIDENCIAS_ANTES_DEPOIS.md).
